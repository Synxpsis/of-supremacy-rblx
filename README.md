# Supremacy Live!

A 12–24 player, real-time, screens-only (GUI) map supremacy PvP game for Roblox, desktop-first,
running on `OpenFrontCore` — our Luau port of [OpenFront](https://github.com/openfrontio/OpenFrontIO)'s
simulation (`lib/OpenFrontCore/`).
